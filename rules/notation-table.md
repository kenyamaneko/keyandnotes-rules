# 表記の対応表

documentation.md の「語の選び方」に反する表記と、代わりに使う表記を並べる。

| 避ける表記 | 使う表記 |
|---|---|
| 枝、ローカル枝 | ブランチ |
| 秘密情報、秘密の入れ物 | シークレット |
| 配備 | デプロイ |
| 動いている実体 | インスタンス |
| 代役 | スタブ・フェイク・モックのうち実際の種類 |
| 作業ツリー (git worktree の意味) | ワークツリー |
| 偽物 | モック・フェイク |
| 窓 (ウィンドウの意味) | ウィンドウ |
| 版 (バージョンの意味) | バージョン |
| 検証エラー | バリデーションエラー |
| 権威のある検証 | バリデーション |
| 出荷 (ソフトウェアを出す意味) | リリース |
| 払う (指で通知を消す意味) | スワイプ |
| 観測点 | 確認する場所 |
| でどころ、出どころ | 決め方 |
| 担い手 | 指している対象の名前を書く |
| 〜の時計 | 指している値の名前を書く |
| 検証器 | 指している対象の名前を書く |
| (エラーに) 翻訳する | (エラーに) なる |
