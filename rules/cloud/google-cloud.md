# Google Cloud の利用方針

Google Cloud のサービスを使い分けるときに従う規約。`infra-design.md` を Google Cloud について具体化する。

## 実行基盤

| 処理の性質 | 選ぶもの |
|---|---|
| リクエストに応答する処理 (例: 注文 API、リアルタイム通信) | Cloud Run |
| 一度実行して終わる処理のうち、短時間で終わり、関数一つに収まるもの (例: 商品画像が保存されたら、サムネイルを作る) | Cloud Run Functions |
| 一度実行して終わる処理のうち、Cloud Run Functions に収まらないもの (例: データベースの移行) | Cloud Run Jobs |
| ステートフルな処理 | GCE |
| ステートフルな処理や複数サービスからなるシステムのうち、ランニングコストを許容できるもの | GKE |

## ホスティング

| 配信の性質 | 選ぶもの |
|---|---|
| 静的なフロントエンドの配信 | Firebase Hosting |
| 静的なフロントエンドの配信のうち、アクセス数が大きく、ランニングコストを許容できるもの | Cloud Storage とロードバランサー |

## データストア

| データの性質 | 選ぶもの |
|---|---|
| ACID 特性や、RDB によるスキーマの表現力が求められる場合 | Cloud SQL |
| 画面や API が一度に使う単位のスキーマで足りる場合 | Firestore |
| 画像や音声などのファイル | Cloud Storage |

## サービス間の連携

| 連携の性質 | 選ぶもの |
|---|---|
| サービスどうしを疎結合に連携させる | Pub/Sub |
