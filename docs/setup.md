# セットアップ

このリポジトリのフックと、コミット前の監査を使えるようにする。

## 前提条件

- このリポジトリをクローンしてある
- git、make、jq、ruby、python3、Claude Code の `claude` コマンドが使える

## 注意書き

- コマンドがエラーを表示したら、エラーの内容に従って原因を直し、同じコマンドを実行し直す
- フックの登録は、git の全リポジトリ共通のフックの置き場の設定を上書きする。上書き前の値は残らない
- 監査の設定の雛形をコピーする操作は、`audit-repos.yaml` があると上書きする。上書き前の内容は残らない

## フックの登録

1. ターミナルで、このリポジトリをクローンしたフォルダに移動する。置き換える値は、`git clone` を実行したフォルダの中にある `keyandnotes-rules` フォルダの場所である。

   ```sh
   cd {{keyandnotes-rules フォルダの場所}}
   ```

   - 想定結果: 何も表示されない
2. このリポジトリのフックを `~/.claude/settings.json` に登録し、すべてのリポジトリの git のフックの置き場を、このリポジトリの git 用のフックに設定する。

   ```sh
   make setup-hooks
   ```

   - 想定結果: 最後の 2 行が、次の文言で始まる

     ```text
     フックを登録した:
     git のフックの置き場を登録した:
     ```

## コミット前の監査の対象リポジトリ

1. ターミナルで、このリポジトリをクローンしたフォルダにいる状態で、監査の設定の雛形をコピーする。

   ```sh
   cp scripts/commit-audit/config/audit-repos.template.yaml scripts/commit-audit/config/audit-repos.yaml
   ```

   - 想定結果: 何も表示されない
2. エディタで `scripts/commit-audit/config/audit-repos.yaml` を開く。
   - 想定結果: 監査対象の一覧に、次の名前の項目が表示される

     ```text
     shop-storefront
     shop-checkout
     shop-common
     ```
3. 監査対象の一覧の項目を、監査するリポジトリの項目に置き換える。フォルダ名と相対パスは、監査するリポジトリのフォルダで確認する。
   - ルールを `rules` フォルダ以外に置くリポジトリは、ルールの置き場を指定する
   - 前提として読ませるドキュメントがあるリポジトリは、そのドキュメントを指定する
   - ルールの置き場もドキュメントも指定する必要が無いリポジトリは、`{}` を書く

   ```yaml
   repos:
     {{リポジトリのフォルダ名}}: {}
     {{別のリポジトリのフォルダ名}}:
       overlay_dir: {{ルールのフォルダへの相対パス}}
       extra_docs:
         - {{ドキュメントへの相対パス}}
   ```

   - 想定結果: 監査対象の一覧に、監査するリポジトリの項目だけが並ぶ
4. ファイルを保存する。
   - 想定結果: エラーが表示されずに保存が終わる
